# Пояснительная записка: Задача T10. Админка: заказы

## Что сделано и почему
- **Матрица переходов (A-05)**: В `src/lib/order-status.ts` реализован движок жизненного цикла (`new → paid/processing → shipped → completed`, `cancelled` из незавершенных). Терминальные статусы защищены.
- **Складская компенсация (A-06)**: При отмене заказа остатки товаров атомарно возвращаются на склад (`$inc`), а счетчик промокода откатывается.
- **Админка заказов (`/admin/orders`, `/admin/orders/[id]`)**: Поиск по номеру/email/клиенту, фильтры по статусам и датам, пагинация, управление статусом, заметки менеджера (`managerComments`), таймлайн (`statusHistory`) и консольные нотификации (A-18).
- **Безопасность (A-09)**: Менеджеры и администраторы имеют полный доступ ко всем заказам, покупатели отсекаются с 403 Forbidden.

## 3 вопроса для защиты с ответами
1. **Каковы правила переходов статусов заказа и почему запрещена отмена из статуса `shipped`?**
   *Ответ:* Разрешены переходы: `new → paid/processing`, `paid → processing`, `processing → shipped`, `shipped → completed`. Отмена (`cancelled`) допускается только из `new`, `paid`, `processing`. Переход `shipped → cancelled` запрещен, так как отправленный клиенту заказ физически находится у курьера/службы доставки и требует регламента возврата после вручения.
2. **Как гарантируется целостность складских остатков при отмене заказа менеджером?**
   *Ответ:* В `updateAdminOrderStatus` при переходе в `cancelled` проверяется, что предыдущий статус не был `cancelled`. Для каждой позиции заказа выполняется атомарная операция MongoDB `Product.updateOne({ _id: item.productId }, { $inc: { stockQuantity: item.quantity } })`. Также декрементируется `usedCount` у примененного промокода.
3. **Отличаются ли права доступа менеджера к товарам (T09) и к заказам (T10)?**
   *Ответ:* Да. Согласно допущению A-09, менеджер редактирует товары только в назначенных категориях (`assignedCategoryIds`), однако видит и обрабатывает **все** заказы магазина без ограничений по категориям, чтобы обеспечивать бесперебойную комплектацию и отгрузку сборных заказов.
